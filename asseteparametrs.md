# Asset Parameters

В этот файл записываем параметры ассетов проекта.

| Название | За что отвечает | Где хранится | Размер изображения |
| --- | --- | --- | --- |
| `logo-make-love-pizza` | Логотип Make Love Pizza на стартовом экране | `public/assets/logo-make-love-pizza.svg` | `654x128` |
| `heart-pixel` | Сердце в левом верхнем углу, показывает жизни/доступ к сессии на главном экране | `public/assets/heart-pixel.png` | `250x250` |
| `pizza-pixel` | Иконка пиццы на кнопке `PLAY` | `public/assets/pizza-pixel.png` | `200x200` |
| `gamepad-pixel` | Иконка геймпада на кнопке `MINI GAMES` | `public/assets/gamepad-pixel.png` | `200x200` |
| `logo-make-love-pizza-pixel-source` | Исходный пиксельный логотип из приложенных файлов, хранится как референс | `public/assets/logo-make-love-pizza-pixel-source.png` | `1536x1024` |
| `logo-make-love-pizza-pixel` | Пиксельный логотип Make Love Pizza на главном экране | `public/assets/logo-make-love-pizza-pixel.png` | `1536x1024` |
| `sound-on-pixel` | Кнопка включённого звука | `public/assets/sound-on-pixel.png` | `200x200` |
| `sound-off-pixel` | Кнопка выключенного звука | `public/assets/sound-off-pixel.png` | `200x200` |
| `PressStart2P-Regular` | Локальный пиксельный шрифт с кириллицей для проекта | `public/fonts/PressStart2P-Regular.ttf` | `116008 bytes` |
| `star-pixel` | Падающие звёздочки на главном экране | `public/assets/star-pixel.png` | `120x120` |
| `orientation-phone-pixel` | Телефон на экране просьбы повернуть устройство вертикально | `public/assets/orientation-phone-pixel.png` | `200x200` |
