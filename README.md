# Make Love Adventures

Промо-игра для Make Love Pizza: мобильный аркадный раннер из коротких мини-игр, билетов и колеса призов.

Проект рассчитан на запуск внутри webview мобильного приложения, но также работает как обычное Vite-приложение в браузере. Базовое разрешение игрового холста: `720x1280`, формат: `9:16`.

## Стек

- TypeScript
- Phaser 3
- Vite
- Web Audio API для синтетических звуков и музыки

## Игровой цикл

Основной режим `Play` использует билет и запускает сессию из 4 мини-игр. На сессию даётся 3 жизни. После победы в мини-игре игрок выбирает: крутить колесо сейчас или идти дальше за более ценным призом. После четвёртой мини-игры открывается финальное колесо.

Режим `Mini Games` нужен для свободной игры и тестирования: можно запускать любую активную мини-игру без билета, каждая попытка получает собственные 3 жизни.

## Активные мини-игры

- `FireStarter` — тайминг печи: достать пиццу в зелёной зоне.
- `ChopChop` — тап-батл против шефа Диди с рулеткой перков.
- `PizzaAssembly` — Knife Hit: воткнуть нужное количество ножей и не попасть в уже воткнутые.
- `RecipeMemo` — memory-игра с рецептами и ограниченным подсмотром.
- `DontWork` — свайп-аркада в духе Fruit Ninja.
- `Surfer` — аркада с удержанием персонажа между препятствиями.
- `DanceBeat` — запомнить и повторить комбинацию стрелок.
- `JeffreySurfer` — Crossy Road-переход через дороги и рельсы.

## Быстрый старт

```bash
npm install
npm run dev
```

Dev-сервер запускается на `http://localhost:5173` и доступен по сети благодаря `--host`.

Для production-сборки:

```bash
npm run build
npm run preview
```

`npm run build` сначала запускает `tsc --noEmit`, затем собирает проект через Vite.

## Билет и webview

Билет можно выдать двумя способами:

- URL-параметр `?ticket=1`
- сообщение из родительского приложения:

```js
window.postMessage({ type: 'mla:grantTicket' }, '*');
```

Игра отправляет наружу события:

- `mla:prizeWon` — игрок выиграл приз
- `mla:sessionEnd` — сессия завершилась победой или проигрышем

Перед production-релизом нужно заменить `'*'` в `postMessage` на whitelist разрешённых origin.

## Добавление мини-игры

1. Создать сцену в `src/minigames/<GameName>/index.ts` и унаследоваться от `BaseMinigame`.
2. Зарегистрировать сцену в `src/main.ts`.
3. Добавить игру в `MINIGAME_POOL` в `src/core/MinigameRegistry.ts`.
4. Добавить название, короткий hint и guide в `src/i18n/ru.ts`.

Сцена должна завершаться через `this.complete({ outcome, score })`. Это единый контракт, по которому раннер понимает результат мини-игры.
