ОПИСАНИЯ ИГР ДЛЯ ГЕНЕРАЦИИ НОВОЙ ВЕРСТКИ

Эта папка содержит отдельный txt-файл для каждой миниигры проекта.
Файлы написаны так, чтобы их можно было использовать вместе со скриншотом текущей верстки как промпт для нейросети-дизайнера.

Структура каждого файла:
- название игры и ключ сцены;
- краткое описание механики;
- логика, которую нельзя менять;
- текущая композиция экрана;
- важные ассеты;
- анимации и состояния;
- требования к новой верстке;
- готовый промпт для генерации.
