================================================================================
  МИНКА: РОВНО НА $5 (FiveDollar)
================================================================================
SCENE KEY: FiveDollar
ОСНОВНОЙ ЦВЕТ ФОНА: #2A1F3D (тёмно-фиолетовый — атмосфера бара/коктейльной)
ВНУТРЕННЯЯ ТЕМА: барная стойка, миксер, ингредиенты с ценами

================================================================================
  СТАТУС
================================================================================

⚠️ ИГРА В РАЗРАБОТКЕ. Финальные механики могут поменяться.
Текущая реализация — рабочий прототип с базовой механикой.

================================================================================
  КОНЦЕПЦИЯ
================================================================================

Логика «собери набор товаров на ровную сумму» в антураже коктейль-бара.
Есть список ингредиентов с разными ценами в центах. Игрок выбирает несколько
и пытается набрать ровно $5.00 (500 центов).

================================================================================
  ЦЕЛЬ ИГРОКА
================================================================================

За отведённое время (40 сек) собрать набор ингредиентов на сумму ровно $5.00.
Превысил — потеря. Не успел / не собрал — потеря. Можно отменять выбор (undo).

================================================================================
  ГЕЙМПЛЕЙ И МЕХАНИКИ
================================================================================

КАТАЛОГ ИНГРЕДИЕНТОВ
- Список ~6-10 ингредиентов с фиксированными ценами (в центах)
- Каждый ингредиент: эмодзи + название + цена
- Например: 🍓 клубника 137¢, 🍌 банан 89¢, 🥥 кокос 213¢, 🌿 мята 47¢,
  🥛 молоко 161¢, 🍯 мёд 79¢

ВЫБОР ИНГРЕДИЕНТА
- Каждый ингредиент — кликабельная карточка в каталоге
- При тапе:
  - Ингредиент добавляется в «корзину» (массив picked)
  - Появляется в зоне «выбранное» — справа от миксера или внизу
  - Сумма обновляется
  - Иконка в каталоге пульсирует / меняет цвет (показывает что выбран)

УДАЛЕНИЕ (UNDO)
- Кнопка «Отменить» или тап по уже добавленному ингредиенту
- Убирает последний добавленный (или конкретный), сумма пересчитывается

МИКСЕР (ВИЗУАЛЬНАЯ ЗОНА)
- Большой круглый «миксер» (Arc) в центре
- Внутри — «жидкость» прямоугольником, уровень которой растёт с увеличением
  суммы (визуально, чем больше суммы, тем выше уровень — но не привязано
  жёстко к точной сумме, скорее юмор)
- Цвет жидкости меняется по типу ингредиентов (микс цветов)

ТАЙМЕР
- Сверху экрана: цифровой таймер «⏱ 12»
- Изначально на 40 секунд (durationMs из initData)
- При нуле — авто-проверка результата

КНОПКА «СМЕШАТЬ»
- Большая яркая кнопка снизу
- При тапе:
  - Если сумма = 500 → win, blendDone = true, анимация миксера, текст «$5!»
  - Если сумма ≠ 500 → текст «$X.XX — не $5!», −время или −жизнь

УСЛОВИЯ ВЫИГРЫША / ПРОИГРЫША
- WIN: смешать ровно на $5.00
- LOSE: время кончилось без точной суммы

================================================================================
  УПРАВЛЕНИЕ
================================================================================

- ТАП по ингредиенту в каталоге = добавить в корзину
- ТАП по «Отменить» = убрать последний
- ТАП по «Смешать» = проверить итог
- ESC = модалка выхода

================================================================================
  UI-ЭЛЕМЕНТЫ
================================================================================

ВЕРХ
- Кнопка-домик (левый верх)
- Заголовок-постер «$5 КОКТЕЙЛЬ» на жёлтом, с лёгким наклоном (PosterText)
- Подсказка под заголовком: «набери ингредиентов на ровно $5.00»
- Таймер справа: «⏱ 12»
- Цель «ровно $5.00» (или просто «$5.00») крупно слева

ЦЕНТР — МИКСЕР
- Большой круг (Arc) ~440×440 или прямоугольник, кремовый с обводкой
- Внутри прямоугольник-жидкость, цвет смешивается из выбранных ингредиентов
- Текущая сумма крупно по центру миксера: «$3.21»
- Анимация перелива при добавлении

КАТАЛОГ ИНГРЕДИЕНТОВ
- Сетка 2×3 или 3×3 карточек снизу или по сторонам миксера
- Каждая карточка: эмодзи + название + цена «137¢»
- При выборе — карточка слегка поднимается / меняет цвет

ВЫБРАННЫЕ (КОРЗИНА)
- Полоска снизу или сбоку с маленькими эмодзи каждого выбранного ингредиента
- Можно тапнуть на эмодзи чтобы убрать (undo)

КНОПКИ ДЕЙСТВИЙ (НИЖНИЙ КРАЙ)
- «ОТМЕНИТЬ» (Undo) — серая или красная, слева
- «СМЕШАТЬ» (Mix/Blend) — большая зелёная, справа

================================================================================
  АНИМАЦИИ И ЭФФЕКТЫ
================================================================================

- При добавлении ингредиента: эмодзи «летит» из каталога к корзине, scale-bounce
- Жидкость в миксере: плавный rise при добавлении (tween по высоте rectangle)
- На «Смешать» при успехе: эмодзи внутри миксера крутятся в спирали,
  затем большой текст «$5! 🎉», звук успеха
- На «Смешать» при неуспехе: красный flash, текст «не $5!»
